# Terrain & Portal Systems Prototype

An Unreal Engine 5 graphics and gameplay prototype exploring terrain manipulation, portals, dynamic materials, projectile systems, and object decals.

## Features

### Projectile-Based Terrain Manipulation

Developed a projectile system that allows the player to modify the terrain by firing projectiles into the environment.

### Portal System

Implemented a functional portal system that allows the player to:

* Look through a portal and see the connected area.
* Walk through the portal.
* View the environment through the linked portal.
* Use dynamic materials as part of the portal rendering system.

### Paint Projectile System

Created a gun that fires randomly selected paint projectiles.

When a projectile impacts another object, it:

* Detects the collision.
* Creates a decal at the impact location.
* Leaves visible paint on the affected object.
